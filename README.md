# Tesis Game

En este repositorio se encuentra toda la documentación sobre el desarrollo del proyecto para Trabajo de Graduación Prosefional de la Universidad del Valle de Guatemala. En la rama "main" se encuentra todo el trabajo hecho por nosotros mientras que en la rama "IAG" se encuentra todo el trabajo asistido por IA.

De igual forma el script `calculos_de_resultados.py` contiene todos los calculos realizados para la sección de resultados para la reproducibilidad de este trabajo.
